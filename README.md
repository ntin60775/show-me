# show-me (ZCode)

Зеркало плагина `show-me` из [humanlayer/skills](https://github.com/humanlayer/skills)
(MIT, © HumanLayer) в упаковке ZCode-плагина: визуальные объяснения
текущей темы — псевдокод, деревья вызовов и компонентов, Mermaid,
диффы и HTML-артефакты.

Отличие от апстрима — security-слой (подробности в [UPSTREAM.md](UPSTREAM.md)):

- HTML-артефакт обязан быть полностью самодостаточным: без CDN, внешних
  шрифтов, картинок и сетевых вызовов — рендер с диска (file://);
- контент репозитория в артефакте экранируется, чтобы не стать живой
  разметкой;
- навык запускается только по явному запросу пользователя.

Установка — каталог `sot-zcode-marketplace`, канал global. Обновления
апстрима — только через синк по UPSTREAM.md с проверкой безопасности.
