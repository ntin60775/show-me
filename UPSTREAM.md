Живой апстрим (MIT, © HumanLayer): монорепо навыков, форкается из него
только `plugins/show-me`. Назначение зеркала — держать **минимальный
diff** с security-правками поверх апстрим-контента, чтобы обновления
забирались явным решением, а не утекали сами. Обзор безопасности при
взятии — 2026-10-29: апстрим чистый (исполняемого кода нет, сети и
секретов нет), три недочёта закрыты нашим слоем.

## Синк с апстримом

```bash
git fetch upstream
git diff upstream/main -- plugins/show-me/skills/show-me/SKILL.md  # конфликтная поверхность = HTML-параграф и guidance
git merge upstream/main
python3 <1c-zcode>/scripts/lint_skill_frontmatter.py skills/
# затем: тег vX.Y.Z → re-pin в sot-zcode-marketplace/marketplace.json →
#        проверка безопасности (dependency-registry.md) → update
```

Правило гигиены: всё, что выражается обвязкой потребителя, — в обвязке,
не в теле форка.
